**Emberfall** — you are the last Ember Warden. The Hearth's flame is all that stands between the living dark and the Ashen horde. Hold the line through 10 waves, pick an upgrade after each one, and slay the Cinder Tyrant.

A complete top-down arena shooter that runs offline in a desktop browser from static files: five enemy kinds with their own behaviour, a boss every five waves, power-up drops, a between-wave upgrade draft, a combo multiplier, synthesized WebAudio sound and music, particles, screen shake, hit-stop, and a best score kept in localStorage. No library, no build step, no network request.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Move with WASD or the arrow keys, aim with the mouse, hold click or Space to shoot. P pauses, M mutes, 1/2/3 pick an upgrade card, R restarts. `?shot=start|play|upgrade|end&seed=N` stages a scene for a screenshot.
